# /new-project

Create a new WebForge project using Playwright extraction and generate pixel-perfect static HTML.

## What It Does

1. **Get project name** (any name accepted)
2. **Get reference website URL**
3. **Run Playwright extraction** using `extract_page.py` from perfect-web-clone
4. **Generate HTML** from extraction JSON using `build-clone.js`
5. **Store project** in `projects/<name>/` with images and fonts
6. **Create GitHub repository** (always private, "Forged by WebForge" description)
7. **Preview** at localhost:3000 using `npx serve`
8. **Verify clone** using MCP screenshots (compare with original)
9. **Push to GitHub** (auto-push)

## New Project Structure

```
projects/
└── <project-name>/
    ├── index.html                    # Generated by Claude
    ├── <project-name>-extract.json   # Playwright extraction data
    ├── images/                       # Downloaded images
    └── fonts/                        # Downloaded fonts (if any)
```

## Implementation

### Step 1: Get Project Name

```bash
echo "🔨 What is the project name?"
read PROJECT_NAME

# Check that name is not empty
if [ -z "$PROJECT_NAME" ]; then
    echo "❌ Project name cannot be empty"
    exit 1
fi

# Check if project already exists locally
if [ -d "projects/$PROJECT_NAME" ]; then
    echo "❌ Project '$PROJECT_NAME' already exists locally"
    exit 1
fi
```

### Step 2: Get Reference URL

```bash
echo "🌐 What is the reference website URL?"
read REFERENCE_URL

# Validate URL
if ! echo "$REFERENCE_URL" | grep -qE '^https?://'; then
    echo "❌ Invalid URL. Must start with http:// or https://"
    exit 1
fi
```

### Step 3: Create Project Directory

```bash
# Get absolute path to agent directory
AGENT_DIR="$(pwd)"

# Create projects directory if it doesn't exist
mkdir -p "$AGENT_DIR/projects"

# Create new project directory
mkdir -p "$AGENT_DIR/projects/$PROJECT_NAME"
PROJECT_DIR="$AGENT_DIR/projects/$PROJECT_NAME"

echo ""
echo "📁 Setting up project directory..."
echo "✅ Project created at: projects/$PROJECT_NAME/"
```

### Step 4: Run Playwright Extraction

```bash
echo ""
echo "🔍 Extracting website data..."
echo "📊 Running Playwright extraction..."
echo ""

# Navigate to perfect-web-clone scripts directory
cd "$AGENT_DIR/.claude/skills/perfect-web-clone/scripts"

# Run extraction
EXTRACT_OUTPUT="$PROJECT_DIR/${PROJECT_NAME}-extract.json"

python extract_page.py "$REFERENCE_URL" --output "$EXTRACT_OUTPUT"

# Check if extraction was successful
if [ ! -f "$EXTRACT_OUTPUT" ]; then
    echo "❌ Extraction failed. Could not find output file."
    exit 1
fi

echo ""
echo "✅ Extraction complete! Data saved to: ${PROJECT_NAME}-extract.json"

# Return to agent directory
cd "$AGENT_DIR"
```

### Step 5: Generate HTML from Extraction JSON (using build-clone.js)

```bash
echo ""
echo "🎨 Generating HTML from extraction data..."
echo ""

# Create images and fonts directories
mkdir -p "$PROJECT_DIR/images"
mkdir -p "$PROJECT_DIR/fonts"

# Use build-clone.js to convert JSON to HTML
cd "$AGENT_DIR/.claude/skills/new-project"

# Try build-clone.js first
if node build-clone.js "$EXTRACT_OUTPUT" "$PROJECT_DIR"; then
    echo ""
    echo "✅ HTML generation complete!"
    echo "   - index.html created"
    echo "   - Images downloaded to images/"
    echo "   - Fonts downloaded to fonts/"
else
    # If build-clone.js fails, use Claude's brain to generate the full site
    echo ""
    echo "⚠️  build-clone.js failed. Using Claude to generate pixel-perfect clone..."
    echo ""

    # Claude will now generate the full site using the extraction JSON
    # Read the extraction JSON and generate complete HTML with:
    # - All CSS inline in <style> tags
    # - All images downloaded to images/ folder
    # - All fonts downloaded to fonts/ folder
    # - Exact computed styles from extraction
    # - Preserve all text content verbatim
    # - Maintain exact layout geometry
    # - Include media queries for responsiveness

    # After generation, verify index.html was created
    if [ ! -f "$PROJECT_DIR/index.html" ]; then
        echo "❌ HTML generation failed"
        exit 1
    fi

    echo ""
    echo "✅ HTML generation complete!"
    echo "   - index.html created (by Claude)"
    echo "   - Images downloaded to images/"
    echo "   - Fonts downloaded to fonts/"
fi
```

### Step 6: Create GitHub Repository (Always Private)

```bash
echo ""
echo "📦 Creating GitHub repository..."

# Setup GitHub auth
export GH_TOKEN=$(grep GITHUB_TOKEN "$AGENT_DIR/.env" | cut -d'=' -f2 | tr -d ' ')
GITHUB_USER=$(gh api user --jq '.login')
GITHUB_EMAIL=$(gh api user --jq '.email // empty')
GITHUB_EMAIL="${GITHUB_EMAIL:-${GITHUB_USER}@users.noreply.github.com}"

# Create private repo
gh repo create "$PROJECT_NAME" --private --description "Forged by WebForge"

echo "✅ Repository created: github.com/$GITHUB_USER/$PROJECT_NAME"
```

### Step 7: Preview with npx serve

```bash
echo ""
echo "🔥 Starting preview server..."
echo ""

# Kill any existing servers on port 3000 first
echo "🧹 Cleaning up port 3000..."
if command -v powershell &> /dev/null; then
    # Windows - use PowerShell
    powershell.exe -NoProfile -Command "Get-NetTCPConnection -LocalPort 3000 -State Listen -ErrorAction SilentlyContinue | ForEach-Object { Stop-Process -Id \$_.OwningProcess -Force }" || true
else
    # Mac/Linux
    lsof -ti:3000 | xargs kill -9 2>/dev/null || true
fi

# Also kill any npx serve processes
pkill -f "npx serve" 2>/dev/null || true
pkill -f "serve" 2>/dev/null || true

# Wait and verify port is free
sleep 3

# Check if port is still in use
if command -v powershell &> /dev/null; then
    while powershell.exe -NoProfile -Command "Get-NetTCPConnection -LocalPort 3000 -State Listen -ErrorAction SilentlyContinue" 2>/dev/null | grep -q "3000"; do
        echo "⚠️  Port still in use, killing again..."
        powershell.exe -NoProfile -Command "Get-NetTCPConnection -LocalPort 3000 -State Listen -ErrorAction SilentlyContinue | ForEach-Object { Stop-Process -Id \$_.OwningProcess -Force }" || true
        sleep 2
    done
else
    while lsof -ti:3000 &>/dev/null; do
        echo "⚠️  Port still in use, killing again..."
        lsof -ti:3000 | xargs kill -9 2>/dev/null || true
        sleep 2
    done
fi
echo "✅ Port 3000 confirmed free"

# Check if npx is available
if ! command -v npx &> /dev/null; then
    echo "⚠️  npx not found. Please install Node.js to use preview."
    echo "   Preview manually with: npx serve \"$PROJECT_DIR\" --listen 3000"
else
    # Start npx serve in background
    cd "$PROJECT_DIR"
    npx serve --listen 3000 > /dev/null 2>&1 &
    SERVE_PID=$!

    # Store PID for cleanup
    echo $SERVE_PID > .serve.pid

    cd "$AGENT_DIR"

    # Show preview URL immediately
    echo ""
    echo "🔥 Preview running at: http://localhost:3000"
    echo "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
    echo "Open the URL above in your browser to see the forged website."
    echo "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
    echo ""
fi
```

### Step 9: Push to GitHub (Always)

```bash
cd "$PROJECT_DIR"

# Set git identity from token owner (not global config)
git config user.name "$GITHUB_USER"
git config user.email "$GITHUB_EMAIL"

git init
git remote add origin "https://github.com/$GITHUB_USER/$PROJECT_NAME.git"
git add .
git commit -m "feat: initial forge

Forged from: $REFERENCE_URL"
git branch -M main
git push -u origin main

cd "$AGENT_DIR"

echo ""
echo "🔥 Project forged successfully!"
echo ""
echo "📦 Project: $PROJECT_NAME"
echo "🔗 GitHub: github.com/$GITHUB_USER/$PROJECT_NAME"
echo "🔥 Preview: http://localhost:3000"
```
